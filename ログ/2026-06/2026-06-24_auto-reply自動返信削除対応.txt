#### 自動返信の特定方法
- auto-replyはCronで毎日 9:00 JST（= 00:00 UTC）に実行
- reviewsテーブルの reply_time カラムにGBP側の返信日時が記録されている
- reply_time の HOUR(UTC)=0 かつ MINUTE<=30 でフィルタ → 9:00〜9:30 JST に返信されたもの
- 追加条件: star_rating が FOUR/FIVE、create_time >= 2026-04-13

#### 件数
- 自動返信候補: 340件（全期間）
- 例: 2026-06-23 は6件（reply_time 00:00:45〜00:01:29 UTC）
- 2026-06-24 は0件（Cron実行前に停止完了 or 該当口コミなし）

#### 自動返信の特徴（DBから確認済み）
- reply_time が 00:00〜00:15 UTC に集中（Cron開始後に順次処理、1件約10秒）
- 返信文は150文字以内、定型的な感謝文（Claude Haiku生成）
- 同一店舗に同じ文面で連続返信されるパターンあり
- 英語口コミには英語で返信

#### export-auto-replies.js — 自動返信一覧をスプレッドシートに書き出し
- Supabaseから全口コミ取得（14,535件）→ 時刻フィルタで340件に絞り込み
- スプレッドシート: 1Nc_b-DSGyKClIs1KHS_Bb70vMrKffn6jyVmYXFTiqtI
- シート名: 「auto-reply削除対象」
- A列にチェックボックス（デフォルトOFF）
- 列: 削除チェック/店舗名/投稿者/星/口コミ内容/自動返信内容/口コミ日時/返信日時/review_id/DB id
- 実行済み、340行書き出し完了

#### delete-auto-replies.js — チェック済み行の返信をGBP APIで削除（未実行）
- スプレッドシートのA列=TRUEの行を取得
- Go API経由でGBP OAuthトークン取得
- shop_name → GBPロケーションパス解決（Go API /api/gbp/account）
- GBP API v4 DELETE /{location}/reviews/{reviewId}/reply で返信のみ削除（口コミ自体は残る）
- Supabase の reply_comment, reply_time を NULL に更新
- K列に結果（削除済み/失敗/スキップ）を書き戻す
- レート制限対策: 1件ごとに500ms待機

### 重要な注意点
- auto-replyのコードは reply_comment を UPDATE するだけで、「自動返信した」というログを残していなかった
  → 今後、外部アクション（GBP投稿・返信・削除）を行う機能には必ず実行ログテーブルを作ること
- reply_time はGBP APIから sync-reviews で取得した値（auto-reply自体はreply_timeを書いていない）
- 時刻フィルタ（9:00-9:30 JST）は推定であり、手動で9時台に返信したものが混入する可能性はゼロではない
  → ユーザーがスプレッドシートで目視確認してからチェックを入れる運用で対処
