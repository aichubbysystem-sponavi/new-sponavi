## 背景（要望）
LINE（Rena）から「今回投稿する店舗」が20件ほどテキストで送られてくる。
現状は投稿管理 > Step1「店舗を選んで投稿」で、702店舗のリストから
Ctrl+Fで1件ずつ探してチェックを入れている。件数が増えると時間がかかる。
→ 貼り付け＋Enterで自動チェック、見つからない店舗は教えてほしい。

## 照合ポリシー（誤チェック事故を防ぐため段階を分けた）
1. 完全一致（NFKC + 小文字化 + 空白除去）        → 自動チェック
2. 記号無視の完全一致（括弧・中黒等を除去）      → 自動チェック
3. 1/2で候補が複数（同名店舗）                   → 自動チェックせず「要確認」
4. 一致なし                                      → 「未検出」。類似候補は提示するが自動チェックしない
※ 部分一致では絶対に自動チェックしない。
   実データ確認: 370店舗中3件（'CHILLRI' 等）が他店舗名の部分文字列になっており、
   部分一致で自動チェックすると別店舗を巻き込む。

## 実データでの精度検証
sql/2026-08-01_rpa_sheet_shop_check.sql の店舗名370件を店舗マスタ代わりに使用し、
LINEで実際に送られてきた20店舗を照合した結果:
  完全一致 20 / 記号無視一致 0 / 部分一致 0 / 未検出 0  → 20/20 (100%)
また同リスト370件について
  - 正規化（空白除去+小文字化）後の名前重複: 0件
  - 記号除去後の名前重複: 0件
→ 現状のデータでは1〜2の段階だけで一意に決まる。3の分岐は保険。

## UI仕様
- テキストエリアに複数行貼り付け → その場で自動照合（onPasteで実行）
- Enter = 照合実行 / Shift+Enter = 改行（IME変換中のEnterは無視）
- 既定は「置き換え」（貼り付けた店舗だけが選択される）。
  チェックボックス「既存の選択に追加する」で追加モードに変更可
- 結果を 一致N件 / 要確認N件 / 未検出N件 / 重複行N件 でバッジ表示
- 未検出・要確認はボタンで1件ずつ手動チェック可（「もしかして」候補付き）
- 行頭の「・」「1.」「- 」等、全角空白、空行、重複行は自動で処理

## 注意（既存仕様として確認したこと）
posts/page.tsx:586 の handleCreate は
  targetIds = bulkPostMode ? bulkPostShopIds : [selectedShopId]
であり、Step1「店舗を選んで投稿」で選んだ postTargetShopIds は
手動の新規投稿では使われない（使われるのは「シートから自動投稿」と
「AI一括生成」の filterShopNames のみ）。
そのため手動投稿でも20店舗指定できるよう、「系列店にも同時投稿」側にも
同じ貼り付けUIを入れてある。
