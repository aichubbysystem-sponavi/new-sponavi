## 本番DBで確認した事実（scratchpad q.py / q2.py / q3.py、読み取りのみ）
- 対象818店舗（未解約・gbp_location_nameあり）のうち 2026/8 を持つ店舗 0。最新月が2026/7 = 462、キャッシュ無し = 331
- 監査ログ「検索語句同期」1142件（12:47〜13:35 JST）。試みたがキャッシュ更新が無い店舗 349 = API が「0ヶ月」
- 349のうち286店舗は口コミが取れている（うなぎや花道 難波店 2,518件など）→ 検索語句が無いはずがない
- gbp_full_path のアカウント別に綺麗に分かれる:
    取れない: accounts/111031567193825395772(192) / 113763883174026708669(90) / 113420220192759473973(33) / 103627062235899273680(9)
    取れる  : 111148362910776147900(238) / 111745538139442406392(108) / 103024620946642977455(64) / 106785837620168419813(60)
- system_oauth_tokens は1行のみ・期限切れ。フォールバック元は system.tokens RPC(get_valid_tokens)

## 原因
- gbp-search-keywords.ts / gbp-performance.ts が getOAuthToken()（Go API主トークン1本）だけで Performance API を叩いていた
- 口コミ同期(cron/sync-reviews)は 2026-08-15 に getFallbackTokens + 401/403/404 再試行を入れたが、検索語句・指標側には未導入
- 403/404 を「API returned 0 months of data」として握りつぶし console.log にしか出ないため、画面は「同期失敗0」

## 8月分について（別問題）
- 成功している466店舗でも 2026/8 は0件 = Google の月次検索語句が 9/5 時点で未提供。毎月5日 Cron は早すぎる
